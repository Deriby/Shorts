O WFP principal mantém os três segmentos, o recurso de catálogo e os ajustes de cor do fundo salvo no Ted. O WFP **Fundo_Local** usa o fundo azul e rosa criado a partir da paleta visível na miniatura do arquivo do usuário. Essa versão serve de alternativa se o recurso de catálogo do Filmora estiver ausente e é a base visual do MP4. Os dois WFPs incluem Glow, Text Vibrate, Grunge_Jitter, Basic Zoom In e Fast Bounce nativos, com os efeitos usados em momentos específicos.

O WFP recebido guardava referências para um sinal de abertura e um Vine Boom no catálogo. Como os binários não vieram no envio, a revisão usa dois WAVs recriados nos mesmos pontos da montagem. O novo swoosh é do banco A87, ID 17-2zC_MgCkeFDAhnO8sZBMFuexsuEuyU, com corte a partir de 0,196 s, duração de 0,4 s e ganho editável de −9 dB. O WAV original permanece intacto no ZIP.
