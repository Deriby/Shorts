# Garagem low poly reutilizável

Coleção `Massacote | garagem low poly` em [Garagem_Driver.blend](Garagem_Driver.blend), criada no short 007. Inclui garagem, marcações, pilastras, carro, banco, volante e barra de chefão opcional. Não inclui narração, referência pessoal, quarto nem avatar.

No Blender, usar **File → Append → Collection**. O vazio `GARAGE | reusable origin` controla o conjunto, com o carro na origem. As janelas são abertas para permitir leitura do rosto. O banco e o volante foram ajustados ao Dery sentado, preservando as proporções do personagem.

O ator e os contatos usados na animação estão no [projeto do episódio](../../../shorts/007-verdadeiro-chefe-driver/production/output/Dery_Driver.blend). Para gerar novamente este pacote: executar `production/save_garage_asset.py` com esse projeto aberto.
