# Entrada de castelo low poly

Coleção `Massacote | entrada de castelo` em [Entrada_Castelo.blend](Entrada_Castelo.blend), criada para o primeiro bloco de “Personagens que a internet estragou”. Inclui parede, porta, colunas, ferragens, piso, tochas e uma silhueta opcional de chapéu.

Usar **File → Append → Collection**. O vazio `CASTLE | reusable origin` move o conjunto. Não inclui avatar, voz, mídias do usuário ou câmera; a precisão PS1 deve ser configurada para a câmera da próxima produção.

O projeto com atuação e sincronismo está na [produção da Lady](../../../shorts/008-personagens-que-a-internet-estragou/production/01-lady-dimitrescu/). A silhueta é uma ilustração cômica, não uma reprodução completa do modelo da Lady.
