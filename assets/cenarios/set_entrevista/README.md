# Set de entrevista low poly

Coleção `Massacote | set de entrevista` em `Set_Entrevista.blend`. Paredes e piso adaptados da sala de reunião, duas cadeiras orientadas uma para a outra, detalhe amarelo e moldura com superfície neutra. Origem central X=0.

Não contém avatar, rig, voz, gameplay, câmera ou imagens do pacote. As cadeiras preservam a disposição usada com os dois Derys sentados na produção da Tracer. Aplicar `assets/personagens/dery/ps1_precision.py` com a câmera da nova cena.

A fonte da disposição, das poses e dos enquadramentos é `shorts/008-personagens-que-a-internet-estragou/production/07-tracer/build_short.py`. Para reextrair a coleção, carregar o master horizontal e executar `save_interview_asset.py`.
