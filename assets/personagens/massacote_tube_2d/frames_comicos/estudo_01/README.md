# Frame cômico — close hiper-detalhado

Primeira prévia da ideia solicitada pelo usuário: uma mudança brusca do desenho normal para uma pintura muito detalhada do personagem, como um close cômico de animação. A reação desta prévia é constrangimento/nervosismo, com suor, poros, fios de bigode, marcas nas lentes e textura do boné.

[Ver/baixar o PNG](Frame_01_Constrangimento_HiperDetalhado.png).

Manter o boné roxo, óculos vermelho/azul, bigode cobrindo a boca, cavanhaque e identidade do Massacote. O detalhe exagerado funciona como insert pontual ligado à fala/piada, com zoom seco e pausa antes de voltar à edição normal. A duração depende da reação; não há quota fixa de uso.

Este arquivo é uma prévia de linguagem visual, ainda sem aprovação estética registrada. O personagem normal e os projetos existentes permanecem intactos. Outras reações possíveis para o banco: desconfiança, nojo, cansaço extremo e satisfação absurda.
