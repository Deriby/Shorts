# Prévia — olhos alongados e traço digital solto

O usuário pediu olhos mais estreitos/alongados como os dele e, em seguida, um acabamento parecido com um desenho digital amador no IbisPaint, sem ficar artificial. A proposta combina essas solicitações: contornos levemente irregulares, detalhes simplificados e olhos alongados, mantendo boné, cabelo, bigode/cavanhaque, jaqueta e corrente. Boca continua coberta pelo bigode.

Imagem produzida com image_gen, RGBA 1024×1536. O PNG preserva transparência; o JPG com fundo claro serve apenas para visualizar a arte. Estudo rejeitado pelo usuário, que pediu uma nova versão na linguagem de Samurai Jack mantendo o acabamento amador. A biblioteca aprovada e a prévia de animação continuam intactas.
