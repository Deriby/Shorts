# Prévia de estilo — Star vs. as Forças do Mal

Estudo solicitado pelo usuário para avaliar o personagem do Massacote Tube nessa linguagem de desenho 2D. PNG RGBA 1024×1536, com transparência. Mantidos boné para trás, cabelo castanho, bigode cobrindo a boca, cavanhaque, jaqueta roxa/vermelha e corrente. Contornos mais leves, olhos maiores e formas simplificadas.

A proposta aguarda avaliação. A biblioteca aprovada de dez poses e a prévia de conversa anterior continuam intactas; esta imagem ainda não é uma substituição do personagem ativo.
