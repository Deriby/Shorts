# Massacote Tube — personagem 2D

Base visual aprovada pelo usuário no anexo da conversa: boné roxo para trás, cabelo castanho avermelhado, bigode largo enrolado e cavanhaque, jaqueta roxa com vermelho e corrente clara. Este personagem pertence ao Massacote Tube, para conteúdos sobre desenhos. A biblioteca 3D do Massacote Games permanece independente.

O lote inicial contém dez poses novas para avaliação em [`lote_01/`](lote_01/). **A base foi aprovada; as poses novas ainda aguardam avaliação.** O lote de cem só deve ser produzido depois desse retorno.

Abra [`lote_01/galeria.html`](lote_01/galeria.html) para consultar os PNGs e a sequência de fala. Há catálogo JSON e banco SQLite pesquisável. Os arquivos são novas variações produzidas com image_gen a partir do anexo; o PNG neutro não é o arquivo original enviado pelo usuário.

Regra permanente: a boca fica sempre coberta pelo bigode, inclusive em risadas e sustos. Na fala, somente a região do bigode deve mudar; corpo, olhos e cabeça ficam fixos no ciclo básico.
